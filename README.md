# Malks NFT Garage - Copilot CLI

A command-line interface tool for Malks NFT Garage with Copilot-like functionality.

## Installation

```bash
npm install
```

## Usage

### Basic Commands

Run the CLI with:

```bash
npm start
```

Or if installed globally:

```bash
copilot-cli
```

Running the CLI without arguments displays the built-in help menu with all available commands.

### Available Commands

- `copilot-cli` - Display help information (default)
- `copilot-cli help` - Display help information
- `copilot-cli version` - Display version information
- `copilot-cli interactive` - Start interactive mode
- `copilot-cli info` - Display project information

### Interactive Mode

Start the interactive mode to navigate through available options:

```bash
copilot-cli interactive
```

This will present you with a menu of actions to choose from.

## Development

### Running Locally

```bash
node bin/copilot-cli.js
```

### Making the CLI Executable

On Unix-based systems, ensure the file is executable:

```bash
chmod +x bin/copilot-cli.js
```
